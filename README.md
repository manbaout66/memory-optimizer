# Memory Optimizer（内存优化工具）

一个轻量、开源的 Windows 内存优化小工具，原理与知名 MC 启动器 **PCL** 的内存优化一致：调用 Windows API 将各进程的工作集（物理内存页）换出到虚拟内存（页面文件），让任务管理器的可用内存数字立刻上升。

带图形界面（GUI），一键清理、实时内存监控、可自定义间隔的定时清理、开机自启、运行日志，全部集成在一个窗口里。

> ⚠️ **重要说明**：本工具的效果是"腾出物理内存"，**并非真正释放内存**——数据会被换到硬盘上的页面文件，程序下次用到时会重新读回（可能短暂卡顿）。它适合"内存不够用、临时要开大程序"的场景，不适合作为日常提速工具。

---

## 功能特性

- **一键清理内存**：遍历所有可访问进程，调用 `SetProcessWorkingSetSizeEx` 压缩工作集，并显示本次腾出的内存量
- **实时内存监控**：可用/已用/总内存 + 占用率进度条，每 10 秒自动刷新
- **定时清理**：间隔 **1~720 分钟可自定义**，后台静默运行，支持开机自启，关闭窗口不影响
- **运行日志**：记录每次清理的时间、成功/跳过进程数、腾出内存
- **纯脚本零依赖**：仅使用 Windows 自带的 PowerShell 5.1+ 和 .NET 框架，无需安装任何东西

## 快速开始

### 方式一：图形界面（推荐）

```powershell
powershell -ExecutionPolicy Bypass -File .\memory-tool.ps1
```

打开窗口后：

1. 顶部实时显示内存状态；
2. 点 **「一键清理内存」** 立即清理；
3. 在 **「定时清理」** 区域设置间隔（分钟）→ 点 **「应用间隔」** → 点 **「开启定时清理」**。

### 方式二：命令行

| 参数 | 作用 |
| --- | --- |
| `-silent` | 静默清理一次，不弹窗 |
| `-watch [-Minutes 60]` | 后台常驻，按间隔自动清理（默认 30 分钟，合法范围 1~720） |
| `-info` | 弹出当前内存状态 |
| `-schedule [-Minutes 60]` | 开启定时清理（后台进程 + 开机自启项） |
| `-stop` | 关闭定时清理 |

示例：

```powershell
# 后台每 1 小时清理一次（常驻进程）
powershell -ExecutionPolicy Bypass -File .\memory-tool.ps1 -watch -Minutes 60

# 开启开机自启的定时清理，每 15 分钟一次
powershell -ExecutionPolicy Bypass -File .\memory-tool.ps1 -schedule -Minutes 15
```

## 工作原理

```text
进程工作集(物理内存)  --SetProcessWorkingSetSizeEx(handle, -1, -1, 0)-->  换出到页面文件(硬盘)
```

- 对每个可访问的进程，以最小工作集调用 `SetProcessWorkingSetSizeEx`，把不活跃的物理内存页置换到虚拟内存；
- 系统进程及权限受限的进程会被自动跳过，不影响系统稳定；
- 数据没有丢失，仅改变存放位置；程序重新访问时会自动换回（产生一次读盘延迟）。

**优点**：物理内存立刻腾出，适合内存紧张时应急；**代价**：换回时短暂卡顿，机械硬盘更明显；频繁清理会增加硬盘读写（对 SSD 有轻微写入损耗）。

## 安全说明

- **纯本地运行**：不联网、不上传任何数据、不收集统计信息；
- **最小权限**：仅调用系统内存管理 API（`kernel32.dll`）、创建/删除启动文件夹快捷方式、按命令行白名单匹配停止自己的后台进程，不做任何其他系统修改；
- **输入校验**：定时间隔参数使用强类型 `[int]` 绑定并限制在 1~720 分钟，GUI 控件同样限制范围，非法输入自动回退默认值；
- **进程匹配安全**：停止后台进程时按 `memory-tool.ps1` + `-watch` 命令行特征精确匹配，不会误杀其他进程；
- 如需加固，可自行修改 `Stop-TimerProcess` 或改用计划任务（需要管理员权限）。
